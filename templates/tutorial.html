How to Use the Powerful Engine

This guide will walk you through the core features of the Predictability Score™—from basic data analysis to the institutional-grade Sliding Window temporal engine.

Step 1: Enter Your Data

The engine requires a dataset to analyze. You can either type them in manually or upload a raw data file.

  • Type or paste your numbers into the main text box.
  • Numbers can be separated by commas, spaces, or new lines.
  • A minimum of two data points is required for a valid predictability score.

Example: 10, 12, 15, 11, 13

Step 2: Tune the K-Factor™

Our proprietary Volatility Constant (k) allows you to define the risk tolerance of the calculation. A higher 'k' increases sensitivity to inconsistency.

  • 🏈 Sports (k=0.5): Optimized for high-variance performance metrics.
  • 📊 Standard (k=1.0): The baseline for balanced business KPIs.
  • 📈 Finance (k=2.0): Higher sensitivity for risk-adjusted asset analysis.
  • 💊 Pharma (k=15.0): Zero-tolerance precision for manufacturing quality control.

Note: Advanced K-Factor modes require a Pro or API account.

Step 3: Sliding Window Analysis (Premium)

For temporal data, use the Sliding Window mode to identify 'Data Drift.' This engine calculates a rolling score, allowing you to see exactly when stability starts to break down.

  1. Toggle the mode selector from "Standard" to "Sliding Window."
  2. Set your Window Size (N). This determines how many data points are analyzed in each rolling step.
  3. The resulting chart will show the stability of your system over time.

Step 4: Institutional API Access

Integrate the Predictability Score™ directly into your own software stack. Our API supports both standard and sliding window analysis.

  • API Basic: Access the core calculation engine via REST.
  • API Business/Institutional: High-throughput access including the Sliding Window temporal engine.

Your API Key can be found in your dashboard after upgrading to an API tier.

Step 5: Uploading a File (CSV or TXT)

Analyze massive datasets instantly by uploading raw files.

  1. Click the "Upload .CSV or .TXT File" button.
  2. Preview the raw data and click the header of the column you wish to analyze.
  3. The engine will automatically extract the numerical data and run the analysis.

Step 6: Saving and Comparing

Build a library of analyses and compare them head-to-head to identify your most reliable assets.

  1. Name your analysis and click "Save" to store it in your dashboard.
  2. Organize results into folders for structured reporting.
  3. Select multiple saved analyses and click "Compare" to visualize their reliability streams simultaneously.
